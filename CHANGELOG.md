# Changelog
All notable changes to this project will be documented in this file.


## [1.2.0]
- Final feature requests:
  - Implemented `search_feedback.py` to search feedback by student name.
  - Implemented `count_feedback.py` to count total feedback entries submitted.

## [1.1.0] 
### Added
- Implemented `report_generator.py` to export feedback to a text file.
### Changed
- Created a GitHub Issue titled "Export Feedback Functionality".
- Created a GitHub Milestone titled "v1.1 Release".
- Linked the "Export Feedback Functionality" issue to the "v1.1 Release" Milestone.
- Documentation of this version's changes

## [1.0.1] 
### Added
- Implemented `feedback_summary.py` to summarize feedback, including top scores and grade-wise counts.
### Changed
- Created a new branch `feature/summary` for this functionality.
- Documentation for this version 

## [1.0.0] - Initial Release
### Added
- Implemented `feedback_entry.py` to collect student feedback.
- Implemented `score_calculator.py` to compute the average score.
- Included initial project structure with basic documentation.
